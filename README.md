# Сайт с мини-играми

## Краткое описание
Сайт с шестью мини-играми: от математических примеров до викторины и классической игры «Камень, ножницы, бумага». Игры открываются в отдельном всплывающем окне прямо на странице.

## Игры
1. **Угадай число**: угадай случайное число от 1 до 100.
2. **Простая арифметика**: решай примеры на сложение, вычитание, умножение и деление.
3. **Переверни текст**: введи слово или фразу и получи её наоборот.
4. **Камень, ножницы, бумага**: сыграй против компьютера со счётом.
5. **Викторина**: ответь на вопросы с вариантами ответов.
6. **Генератор случайных цветов**: по клику меняет фон блока игр.

## Адаптивность
- **Десктоп (от 1200 px)**: блок «Об играх» и список мини-игр.
- **Планшет и телефон**: сразу список мини-игр, без блока «Об играх».

## Запуск проекта локально
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/el1ze545/MiniGames.git
   cd MiniGames
   ```
2. Откройте `index.html` в браузере (удобнее через расширение Live Server в VS Code).

Если вы правите стили, меняйте `.scss`-файлы: `style.css` собирается из них автоматически (например, расширением Live Sass Compiler).

## Использованные технологии
- HTML5, CSS3 (Flexbox, Grid), SCSS
- JavaScript (Vanilla)
- Git и GitHub для контроля версий
- GitHub Pages для публикации сайта
- Netlify для превью pull request'ов

## Структура проекта
- `index.html`: страница сайта.
- `style.scss`, `_tablet.scss`, `_mobile.scss`, `_game-modal.scss`: исходники стилей (результат в `style.css`).
- `games-ui.js`: всплывающее окно и логика игр 1–5.
- `hw-9.js`: игра «Генератор случайных цветов».
- `hw-1.js` … `hw-8.html`: учебные задания по курсу, на сайт не подключены.
